# ShirtVN Frontend Dev

## Mô tả
Phát triển frontend cho website **shirt.vn**, hướng tới khách hàng cá nhân (B2C). Frontend kết nối với backend API đã có sẵn.

## Mục tiêu
Hoàn thành frontend của shirt.vn (B2C), kết nối được với backend API hiện có. Từ backend API, dữ liệu và chi tiết đơn hàng được truyền tới xưởng may.

## Luồng dữ liệu
Khách hàng → Frontend shirt.vn → Backend API (đã có) → Dữ liệu và chi tiết đơn hàng → Xưởng may

## Trạng thái hiện tại
- Đang ở giai đoạn **ban đầu, làm từ đầu (scratch)**.

## Việc tiếp theo
Chưa xác định. Gợi ý các việc đầu tiên cần làm rõ:
- [ ] Lấy tài liệu backend API hiện có (danh sách endpoint, xác thực, định dạng dữ liệu đơn hàng).
- [ ] Chốt công nghệ frontend (framework, ngôn ngữ).
- [ ] Liệt kê các màn hình chính cho khách B2C (trang chủ, danh sách sản phẩm, giỏ hàng, thanh toán, theo dõi đơn).
